# Breakout Lab - Completed

## Run

```bash
pip install -r requirements.txt
python main.py
```

## Controls

- Left arrow: move left
- Right arrow: move right
- R: restart after Game Over / Win

## Completed lab tasks

1. Bricks are removed after their required number of hits.
2. Three-life system with Game Over and restart.
3. Normal, Strong, and Unbreakable brick types with different appearances.
4. Score and combo multiplier; missing the ball resets the combo.
